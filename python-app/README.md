# What-s-app-automation - Python (Flask) app

A minimal full-stack Flask application (server-side rendered) scaffold added to this repository.

Quick start

```bash
# from repo root
cd python-app
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
# open http://localhost:5000
```

Run tests

```bash
pytest
```

Docker

```bash
docker compose up --build
```
