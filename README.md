# What-s-app-automation

A scaffolded Node.js + Express starter for the What-s-app-automation repository.

## Requirements
- Node.js 18+
- npm

## Install

```bash
npm install
```

## Run

```bash
npm start
# or for development
npm run dev
```

## Tests

```bash
npm test
```

## Docker

```bash
docker build -t what-s-app-automation .
docker run -p 3000:3000 what-s-app-automation
```
